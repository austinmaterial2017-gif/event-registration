# “现代X好未来”公开报名页视觉调整

## 范围

只调整 GitHub Pages 的参加者公开页面。Google Sheet、两个 Apps Script、管理员页面、签到权限、报名流程与数据结构保持不变。

## 品牌与文字

- 全站公开页面品牌名称统一为“现代X好未来”。
- 删除品牌右侧原有宣传句。
- 首页删除 `SUMMER PROGRAMME / 2026`、原主标题和原说明文字。
- 首页主标题改为“请选择你参加的活动”。
- 页脚品牌名称同步改为“现代X好未来”。
- 空列表与错误提示继续使用清楚、直接的中文。

## 视觉方向：方案 A

采用用户参考图的暖色四阶体系：

- 品牌酒红：`#9D202B`
- 深酒红：`#65040B`
- 奶油底色：`#FFF1C8`
- 杏黄强调：`#FFD58B`
- 正文深色：`#32191B`

顶部使用深酒红背景和奶油色品牌字；页面主体使用奶油底色；活动卡片以杏黄和浅奶油分层；主要按钮使用品牌酒红。取消原有紫色与粉色视觉语言。

## 排版与布局

- 顶部仅保留品牌名称，减少视觉干扰。
- 首页用单一的大标题“请选择你参加的活动”引导操作。
- 活动卡片维持现有响应式结构，强化标题、日期、场地和报名按钮的层级。
- 手机版保留足够间距与可点击面积。
- 保留清晰键盘焦点、可读对比度与减少动画偏好支持。

## 验收

- 所有公开 HTML 不再出现“微光现场”或原宣传文案。
- 首页只以“请选择你参加的活动”作为主视觉信息。
- 公开页面使用指定暖酒红色系。
- 报名、电子票、公开验票页面保持功能完整。
- GitHub Pages 可正常连接公开 Apps Script 并显示活动或正确的空状态。
