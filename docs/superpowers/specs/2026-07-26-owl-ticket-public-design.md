# 现代X好未来：猫头鹰入场券视觉设计

## 目标

把目前只更换颜色、留有大片空白的公开报名网站，重新设计成具有明确品牌个性的“猫头鹰入场券”体验。报名、座位、电子票、二维码、Google Sheet 和 Apps Script 功能保持不变。

## 设计方向

- 采用已确认的 A 版“入场券设计室”。
- 删除首页的大型装饰 `X`。
- 品牌名称继续使用准确文字 `现代X好未来`，其中的 `X` 只是名称的一部分。
- 使用原创卡通猫头鹰作为唯一主视觉，造型友好、聪明、年轻，不采用写实照片。
- 保留指定色板：
  - 酒红：`#9D202B`
  - 深酒红：`#65040B`
  - 奶油：`#FFF1C8`
  - 杏色：`#FFD58B`

## 首页

### 顶部

- 使用奶油色背景和深酒红细线分隔，不再使用整块普通色带。
- 左侧显示 `现代X好未来`。
- 不放品牌旁白或无功能的装饰句子。

### 主视觉

- 左侧显示标题 `请选择你参加的活动`。
- 标题可保留一行简短说明：`讲座、课堂和工作坊，都从一张属于你的入场券开始。`
- 右侧显示原创猫头鹰卡通。
- 不显示大型装饰 `X`。
- 猫头鹰是视觉重点，其他装饰必须克制。

### 活动列表

- 活动卡片采用横向票券造型，而不是圆角通用卡片。
- 每张票明确显示日期、时间、活动名称、讲师、地点、剩余名额或座位规则。
- 票根右侧使用虚线和圆形缺口，报名入口显示为清晰箭头或“选择活动”按钮。
- 卡片主要使用深酒红或酒红，并以奶油色文字展示资料。
- 电脑端最多两列；手机端单列。

### 没有活动时

- 不留下大片空白。
- 显示一张完整的猫头鹰提示票，文字为 `目前没有开放报名的活动`。
- 提示参加者稍后再回来查看，但不显示假的活动。

## 其他参加者页面

- 报名页、找回电子票页、电子票和验证页统一使用相同色板、细线、票根缺口与猫头鹰小标记。
- 表单仍以清楚易读为第一优先，不在每个区块重复大型猫头鹰。
- 电子票本身采用票券视觉，让网站首页与最终凭证属于同一套设计。
- 管理员和工作人员页面不在本次视觉修改范围内。

## 动画与无障碍

- 页面载入时只允许一次轻微的猫头鹰上浮与活动票依次出现。
- 支持 `prefers-reduced-motion`，关闭动画时不影响内容。
- 所有文字颜色达到清楚可读的对比度。
- 键盘焦点必须明显。
- 在 320px 宽度下不得横向溢出或裁切标题。

## 功能边界

- 不修改 Apps Script、Google Sheet 结构或部署网址。
- 不修改报名规则、倒数、座位选择、票务、二维码和签到逻辑。
- 不使用外部图片网址；猫头鹰作为本地 SVG 资产随公开网站发布。
- GitHub 公开包只包含参加者页面和公开视觉资产。

## 验收标准

- 首页与旧版大标题加空白列表的结构明显不同。
- 首页没有大型装饰 `X`。
- 猫头鹰卡通在电脑和手机上均完整显示。
- 有活动时显示票券式活动卡；没有活动时显示猫头鹰空状态票。
- `现代X好未来`、`请选择你参加的活动` 和指定四色准确出现。
- 所有现有自动测试通过，公开包安全检查通过。
- 线上 GitHub Pages 实际显示新样式，且活动列表成功连接现有 Google Sheet 后台。
