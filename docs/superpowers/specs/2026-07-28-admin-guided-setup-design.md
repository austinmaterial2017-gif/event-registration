# 管理员活动设置引导设计

## 目标

管理员建立或编辑活动时，界面必须一直说明“目前正在设置哪个活动”，并根据活动选项自动带到下一项需要填写的内容。管理员不需要自己猜应该按“场次、座位、问题”中的哪一个。

## 核心体验

### 1. 清楚区分新活动与现有活动

- 按“新建活动”后，固定提示条显示“正在建立新活动（尚未保存）”。
- 选择已有活动后，固定提示条显示“正在设置：活动名称”及活动状态。
- 场次、座位、问题、记录和签到区域都沿用同一个活动提示，不允许看起来像在编辑另一个活动。

### 2. 根据选择决定下一步

活动保存成功后，系统检查活动设置并自动跳到第一个仍需要设置的项目：

1. 场次选择规则不是“无需选择”时，先跳到“场次”。
2. 座位模式不是“自由入座／无座位”时，在场次完成后跳到“座位”。
3. 如果还没有报名问题，跳到“问题”。
4. 所有必需项目都有内容后，停在活动摘要，并显示“基本设置已完成”。

没有启用的功能会略过，不要求管理员填写无关项目。

### 3. 相关设置才显示

- 选择不需要场次时，活动表单隐藏最少／最多场次数量，并说明参加者不需要选讲座场次。
- 选择需要场次时，显示场次数量规则，并提示保存后建立讲师、日期、时间和地点。
- 选择自由入座／无座位时，隐藏座位区域输入。
- 选择需要选座时，显示座位区域输入，并提示保存后开放或生成座位。
- 报名问题仍由管理员一个一个建立，但参加者会在同一份报名表一次填写全部可见问题。

### 4. 每次操作都有明确反馈

- 按下保存后，按钮立即显示“正在保存…”并暂时禁止重复点击。
- 成功后显示具体结果，例如“场次保存成功”或“座位已开放”。
- 失败时保留已填内容，并说明是哪一项没有保存。
- 自动跳转前显示一句短提示，例如“活动已保存，下一步请建立场次”。

## 数据与安全

这项改动只改变管理员页面的显示和引导，不改变活动、场次、座位、报名问题或参加者资料的储存方式。每个活动仍使用自己的私人 Google Sheet；参加者只看到当前开放活动的公开内容。

## 测试

- 新活动与现有活动的提示必须不同。
- 不同场次和座位组合必须跳到正确的下一步。
- 没启用的设置必须略过。
- 现有活动切换后，所有表单必须带上正确活动 ID。
- 自动跳转不能造成第二次保存或重复建立资料。
- 参加者的选场次、选座、填表、提交、票券及二维码流程必须继续通过原有测试。
