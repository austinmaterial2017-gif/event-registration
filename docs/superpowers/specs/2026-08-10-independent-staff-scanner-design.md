# 独立手机扫码页设计

工作人员 Apps Script 页在 iPhone Safari 的内嵌框架中无法可靠取得相机权限。新增一个由 GitHub Pages 顶层 HTTPS 提供的扫码页，避免内嵌框架限制。

- 工作人员页提供“使用独立手机扫码页”入口，并将当前工作人员验票网址作为返回地址传入。
- 独立页只申请相机、读取 QR，并将扫描结果附加到返回地址的 `scan` 参数后立即返回。
- 返回工作人员页后既有的 `initialScan` 逻辑自动读取凭证；它不会自动写入签到记录。
- 返回地址只接受 Apps Script 的 `/macros/s/.../exec` HTTPS 地址，避免二维码内容造成跳转。
- 无法打开相机时页面保留粘贴二维码网址的备用方式。
